## 🛠️ Stack Tecnológico

### Frontend

- **Next.js 16** (App Router) - Framework React con SSR/ISR
- **TypeScript** (strict mode) - Type safety completo
- **Tailwind CSS** - Utility-first CSS
- **shadcn/ui** - Componentes UI accesibles y personalizables
- **TanStack Table** - Tablas avanzadas con filtros y paginación
- **Recharts** - Gráficos para el dashboard admin
- **Framer Motion** - Animaciones sutiles
- **React Hook Form + Zod** - Formularios con validación robusta
- **Openstreet maps** - Para geolocalización y cálculo de rutas de los usuarios con geolocalización

### Backend

- **Prisma** - ORM de próxima generación para PostgreSQL
- **PostgreSQL** - Base de datos relacional
- **Redis (Upstash)** - Caché y rate limiting
- **Server Actions** - Lógica de backend en Next.js

### Autenticación y Pagos

- **Clerk** - Autenticación completa con SSO, magic links, impersonation
- **Stripe** - Suscripciones recurrentes y pagos
- **PayPal** - Suscripciones recurrentes y pagos

### Búsqueda y Media

- **Meilisearch** - Búsqueda avanzada con filtros facetados
- **Bunny** - Storage de imágenes y vídeos con CDN
- **Resend** - Envío de emails transaccionales
- **React Email** - Templates de email en código

### Herramientas de Desarrollo

- **Bun** - Runtime y gestor de paquetes
- **Jest** - Testing unitario y E2E

### Seguridad

- **Upstash Rate Limit (Upstash)** - SDK de seguridad para evitar consumo de recursos, agentes falsos, bots, scripts, etc

### Infraestructura

- **Hostinger VPS** - Servidor
- **Easypanel** - Docker Compose management
- **GitHub Actions** - CI/CD con preview deployments
