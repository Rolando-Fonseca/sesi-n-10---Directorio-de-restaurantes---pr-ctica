## [1.1.0] - 2026-01-07

### Añadido

- Inicialización de Next.js 16 con Bun.
- Configuración de Tailwind CSS v4 y shadcn/ui (Color de marca: #f67599).
- Configuración de ESLint y Prettier.
- Estructura de layouts: `(public)` para marketing y `(dashboard)` para administración.
- Instalación de Zod para validaciones seguras.
- Componente `AppSidebar` con navegación base.
